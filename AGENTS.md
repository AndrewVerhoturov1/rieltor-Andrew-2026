# Правила репозитория

## Ветки

- В репозитории используется ровно одна ветка: `main`.
- Не создавать, не использовать и не публиковать другие ветки.
- Все изменения выполнять непосредственно в `main`.

## Коммиты и GitHub

- Каждое изменение обязательно фиксировать отдельным коммитом.
- После каждого коммита обязательно выполнять `git push origin main`.
- Не оставлять изменения незакоммиченными и не завершать работу до успешной отправки на GitHub.
- Локальная ветка `main` и `origin/main` должны иметь одну и ту же историю и указывать на один и тот же коммит.
- Перед завершением работы проверить чистоту рабочей папки и совпадение `main` с `origin/main`.
- Не использовать принудительную отправку и не переписывать историю без отдельного явного разрешения.

## Проверка перед завершением

```powershell
git fetch origin main
git status --short --branch
git rev-parse main
git rev-parse origin/main
```

Работу можно считать завершённой только если рабочая папка чистая, обе контрольные суммы совпадают, а последний коммит успешно отправлен на GitHub.
